# ئۆتۆکورد - AutoKurd Marketplace

پلاتفۆرمی فرۆشتنی ئۆتۆمبێل و پارچەی یەدەگ بۆ بازاڕی کوردستان و عێراق.

## تایبەتمەندییە سەرەکییەکان
- پشتگیری سێ زمان (کوردی، عەرەبی، ئینگلیزی)
- ڕووکاری بەرچاو و واکنشدار (PWA)
- گەڕانی پێشکەوتوو و ڕێکۆمێندەیشن
- سیستەمی نامە و ئاگادارکردنەوەی ڕاستەوخۆ
- پەسەندکردنی فرۆشیاران و متمانەپێکراوی
- ئەنالیتیکسی تێروتەواو بۆ فرۆشیاران و ئەدمین
- پارەی ئۆنلاین لە ڕێگەی ZainCash و FIB Bank
- فەیڤەریت و ئاگاداری باڵا

## دامەزراندن

### پێشنیازەکان
- Node.js 18+
- MongoDB 6+
- هەژماری Cloudinary بۆ وێنە
